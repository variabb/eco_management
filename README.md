## Швидкий запуск у PyCharm

1. Відкрити папку як Python-проєкт; налаштуйте інтерпретатор (Python 3.10+).
2. Створіть віртуальне середовище, якщо ще немає:
   `python3 -m venv .venv` і `source .venv/bin/activate` (macOS).
3. Встановіть пакети: `python -m pip install -r requirements.txt`.
4. Запустіть: `python -m streamlit run app.py`.
5. У лівому меню оберіть **«📐 Енергетичні індикатори (ЛР №2)»**.
6. Оберіть рік, підрозділ і ресурс; перемикайте вкладки для розрахунків.

До архіву включено вже наповнену **`energy.db`**. Старі дані лабораторної №1 залишилися без змін.

## Файли

- `app.py` — головна програма Streamlit, всі вкладки ЛР №1 та ЛР №2;
- `database.py` — основна схема SQLite (ЛР №1);
- `energy_data.py` — генерація вихідних даних (ЛР №1);
- `lab2_data.py` — нові таблиці та моделювання показників ЛР №2;
- `indicators.py` — формули індикаторів;
- `lab2_page.py` — сторінка ЛР №2 із таблицями, розрахунками й формами;
- `test_lab2.py` — автоматичні тести;
- `export_lab2.py` — експорт CSV у `exports/`;
- `energy.db` — підготовлена модельна SQLite-база з даними за 2016–2025 рр.

## Команди

```bash
python test_lab2.py
python export_lab2.py
python -m streamlit run app.py
```
